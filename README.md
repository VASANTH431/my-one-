# my-one-

A romantic, luxury-themed Birthday Surprise web experience created with love for Kavya ❤️.

## ✨ Features
- **Cinematic Landing Page**: Animated envelope, floating golden stars, ambient love music.
- **Interactive Bow & Arrow Challenge**: Aim and shoot Cupid's golden arrow to unlock the heart with celebratory confetti & hugging hearts animation.
- **Heart Tree of Love**: Blooming love tree with hundreds of dense hearts, falling petals, and dedication quote.
- **Memories Gallery**: Curated photo gallery with polaroid frames, romantic quotes, and memory moments.
- **Love Letter & Cards**: Handwritten love letters and interactive envelopes.
- **Birthday Countdown & Cake Wish**: Real-time birthday countdown and interactive cake with blowable candle.
- **Final Starry Night Sky**: Floating lanterns, firework stars, and romantic proposal.

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the celebration.
